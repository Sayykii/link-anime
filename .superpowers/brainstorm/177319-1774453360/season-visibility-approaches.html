A: Inline Season Pills

Season badges appear directly under each show name in the existing shows list. Compact, scannable at a glance. Season input auto-suggests the next available number.

B: Expand on Select

Shows list stays clean. When you click a show, it expands inline to reveal season details and the season input — like an accordion. More detail without cluttering unselected shows.

C: Split Panel

Show list on the left, season detail on the right. Master-detail pattern. Shows the most info but takes more space — might feel heavy for a wizard step on mobile.

All approaches include:

  • Season number auto-fills to the next available (e.g., if S1-S3 exist → defaults to 4)
  • Episode counts per season so you can verify completeness
  • Works with the existing show data (Show.seasons is already available)
